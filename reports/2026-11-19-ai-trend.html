AI動向

📅 2026-11-19 ⏱ 約11分で読めます 🗂 10トピック

概要

  • OpenAIの「GPT-6.2 Astra／Sol」とマイクロソフトの「MAI Code 2」が発表され、性能だけでなくコスト効率とトークン効率が争点になっています。
  • Geminiの「タスク」モードが日本で無料提供され、AIが利用者の代わりに実際の行動を実行するエージェント型AIが一般ユーザーにも広がり始めました。
  • 一方で、NotionのAIチャット流出のおそれ、AIによる脆弱性発見の高度化、思考過程（CoT）の監視可能性の問題など、安全性とセキュリティの課題も同時に表面化しています。

OpenAI「GPT-6.2 Astra／Sol」：効率重視へ

  • OpenAIは新モデル「GPT-6.2 Astra」と「GPT-6.2 Sol」を発表しました。少ない出力トークンでより高い成果を出すことが最大の訴求点です。
  • 上位モデルのAPI料金は2割引きとなり、上位プラン「Pro 200」でも高速応答の「Ultrafast」が利用可能になりました。
  • 出力トークンの削減は、API料金の直接的な節約と応答待ち時間の短縮の両方につながります。エージェント処理のようにモデルを何度も呼び出す用途ほど効果は大きくなります。
  • フロンティアモデルの競争軸が「最高性能」から「同じ仕事をどれだけ安く速くこなせるか」へ移りつつあることを示す発表です。

マイクロソフト「MAI Code 2」：コーディングAIの価格競争

  • マイクロソフトは独自のコーディング向けAIモデル「MAI Code 2」と軽量版「MAI Code 2 Flash」を発表しました。高性能と低価格の両立をうたっています。
  • 同社はOpenAIの主要パートナーでありながら、自社開発モデル「MAI」シリーズを強化しています。コーディング領域でも独自路線が鮮明になりました。
  • 上位版と軽量版の2段構成は、難しい設計判断と大量の定型コード生成を使い分ける実務の需要に合わせたものとみられます。
  • GPT-6.2の値下げと合わせて、開発者向けAIは本格的な価格競争の局面に入ったといえます。

Gemini「タスク」モード：エージェントAIが日常へ

  • Googleは、Geminiが電話や支払いまで代行する「タスク」モードの日本での無料提供を始めました。
  • これまでAIエージェントは開発者向けや有料プラン中心でしたが、無料の一般向けアプリで「行動するAI」が使えるようになった点が大きな転換です。
  • 電話や決済のような現実世界での行動は取り消しが難しいため、誤操作時の責任の所在や確認フローの設計が今後の論点になります。
  • 国内でもサービス事業者側に、AIエージェントからのアクセスや予約を前提としたサービス設計が求められる可能性があります。

OpenAIの安全性への取り組み

  • OpenAIは「Managing frontier AI risk: From training to deployment」を公開し、学習段階から実運用まで一貫したフロンティアAIのリスク管理の考え方を示しました。
  • モデルの能力が上がるほど、リリース前の評価だけでは不十分になります。展開後の監視まで含めたライフサイクル全体での管理が重視されています。
  • 同社は「Inside the Codex sandbox」で、コーディングエージェントCodexのサンドボックス（隔離実行環境）の仕組みも解説しました。
  • コードを自律的に実行するエージェントにとって、実行環境の隔離は安全性の要です。その内部を公開することで、企業利用での信頼を高める狙いがうかがえます。

セキュリティ：AIがもたらす新たなリスク

  • NotionでAIチャットの内容が流出したおそれがあり、幹部が日本での対応状況を説明して謝罪しました。
  • 業務SaaSにAIチャットが組み込まれると、社内の機密情報がAIとの会話履歴として蓄積されます。この事案は、そうした履歴が新たな漏えい経路になり得ることを示しました。
  • アットマーク・アイティは「非公開APIだから安全」という前提がもう通用しないと指摘しています。AIによって、公開されていない攻撃対象まで効率的に探索できるようになったためです。
  • 防御側も、外部に公開していないことを安全の根拠にせず、AIを活用した脆弱性診断を前提とした対策へ切り替える必要があります。

研究動向：思考過程の監視可能性

  • arXiv論文「Chain-of-Thought Controllability Can Reduce Chain-of-Thought Monitorability」は、モデルが思考過程（CoT）を制御できるほど、その思考過程を監視しにくくなる可能性を論じています。
  • CoTの監視は、AIの不正な振る舞いや意図しない推論を検出する有力な安全手段とされています。その前提が揺らぎかねない点で重要な指摘です。
  • 推論モデルの高性能化と安全性の監視がトレードオフになる可能性を示しており、OpenAIなどが進めるリスク管理の議論とも直結します。

オープンモデルと推論効率

  • Hugging Faceは、1800億パラメータのMoE（Mixture of Experts）モデルを32GBのRAMで推論する手法をTransformersライブラリで紹介しました。
  • 必要なエキスパートを逐次読み込むストリーミングのアプローチにより、大規模モデルを一般的なハードウェアで動かせる可能性が広がります。
  • クラウドの大規模モデルが値下げを進める一方で、ローカル環境で大規模モデルを動かす技術も着実に進んでいます。用途に応じた選択肢は今後さらに増えそうです。

投資・業界動向

  • ソフトバンクグループの孫正義氏は、Anthropicへの出資を見送った経緯を明かし、「僕の失敗」「あん時入れときゃよかった」と語りました。
  • AI投資で積極姿勢を示してきた孫氏の発言は、Anthropicの企業価値が急速に高まったことを象徴しています。
  • フロンティアAI企業への投資機会は限られており、主要プレイヤーの勢力図がすでに固まりつつあることがうかがえます。

まとめと注目点

  • モデル競争は「性能」から「効率・価格」へ軸足を移しています。GPT-6.2とMAI Code 2はその流れを象徴する発表です。
  • Geminiのタスクモードに代表されるように、エージェントAIは一般ユーザーの実生活に入り始めています。
  • その分、情報流出、AIを使った攻撃、AIの監視可能性といったリスク管理の重要性が増しています。導入する企業には、利便性と安全性を両立させる設計が一層求められます。
